# 🏙️ UrbanAI – Intelligent City & Zone Insights Platform

UrbanAI is a full-stack AI-powered web application that dynamically analyzes **cities, zones, and subzones** to provide **data-driven urban development insights**.  
It automatically generates **investment-ready cards**, stores them safely without duplication, and renders them in a modern, responsive UI.

Built for **GDG Hackathon** with a real-world focus on **real estate, urban planning, and infrastructure intelligence**.

---

## 🚀 Features

### ✅ AI-Powered Zone Analysis
- Dynamic AI analysis for **any city & zone**
- Growth score, classification, builder strategy
- Subzone recommendations & summaries

### ✅ Auto Card Generation
- Cards generated **automatically from AI JSON**
- No hardcoded UI data
- Fully reactive & animated React components

### ✅ No Duplicate Data
- Same city + zone **cannot be saved twice**
- Enforced using SQLite `UNIQUE(city, zone_name)`

### ✅ Multi-City Support
- Pune
- Mumbai
- Solapur

### ✅ Real Backend Architecture
- AI Engine (Node.js)
- Backend API + SQLite
- React + Vite frontend
